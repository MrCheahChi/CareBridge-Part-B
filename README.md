# CareBridge Hospital Web Application

This project upgrades the CareBridge Hospital Management System
from a command-line program into a web-based application.

## Current Function

- Booking Appointment
- Department validation
- Appointment date validation
- Booking confirmation

## Technologies

- Python
- Flask
- HTML
- CSS
